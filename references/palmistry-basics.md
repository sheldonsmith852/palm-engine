# 手相 / 掌纹 知识基础（AI 解读权威源）

> **立场（务必在解读结尾重申）**：手相用于预测性格、命运、寿命、感情的部分，科学上属**伪科学**——Dean et al.(1992) 综述数十年研究无证据支持；Ben-Shakhar et al.(1986) 证明掌纹与性格无关；Wilson & Mather(1974) 证明生命线长度与寿命无显著相关。真正有实证的是**皮纹学（dermatoglyphics）的医学应用**，仅用于某些遗传病辅助筛查，与算命无关。以下传统相学内容属**民俗文化**，仅供参照与批判性阅读。
>
> **资料底本**：本文件综合（1）现代中文完整教程（scu.edu.tw 手相算命、道源阁、易卦网等）；（2）古典《麻衣神相·论掌纹》（宋·麻衣道者）原文与今译；（3）西/印传统（Cheiro/Benham 体系、Hasta Rekha Shastra、四元素手型）。各流派术语有冲突时，以"传统相学内部亦多流派、仅作参考"处理，不夸大确定性。

## 一、传统相学框架（解读主源，属民俗）

### 1. 四主线（三才纹：地纹 / 人纹 / 天纹 + 命运线）

#### 1.1 生命线（地纹 / 生命力纹）
- **定位**：自虎口（拇指与食指间掌边）起，环绕金星丘（大拇指根部）向掌底走。
- **核心**：**长度 ≠ 寿命**，主**生命力强弱、健康趋势、人生重大波折**。
- **读法要点**：
  - 长·深·红润 → 生命力强、抗病力强、不易病；浅·弱 → 较衰弱。
  - 纹粗 → 宜体力/运动；纹细 → 宜用脑。
  - 包围掌丘范围大 → 精力充沛、爱欲旺盛；范围小 → 羸弱易倦。
  - 开头（靠掌边）有**链形纹** → 儿童期体弱多病。
  - 尾端如**流苏** → 防老年病。
  - 有**岛纹** → 某时段生病/住院，岛纹大小=病情轻重与时长。
  - 断口 → 该年龄段阻力或转折（不解读为灾祸）。
  - 末端分支明显 → 中年后生活可能有较大转变。
  - 并行的第二条（**副生命线 / 火星线**）→ 精力旺盛、体力充沛（详见 1.3）。
- **古典**：麻衣"纹深而细者吉，纹粗而浅者贱"；"三纹莹洁无纹破者，福禄之相"。

#### 1.2 智慧线（人纹 / 脑纹）
- **定位**：起与生命线同，向小指方向走，至无名指与小指指缝间停为**标准长度**。
- **核心**：思维、心智、决策风格、自我。
- **读法要点**：
  - 深细为佳 → 思想集中、头脑聪明；岛纹 → 思想不集中、记性差或脑部受挫；起端链形 → 环境影响求学。
  - 太短 → 不够聪明/直观；太长 → 精明过度亦不美。
  - **与生命线起点关系（性格关键）**：
    - 两线合一、一段距离后才分开 → 内向、谨慎、考虑周详；连太长 → 多虑、犹豫不决。
    - 起点一起随即分开 → 果断、随机应变。
    - 两线分开有距离 → 大胆外向、天不怕地不怕。
    - 分开超半公分 → 莽撞不经大脑（川字掌另论，见下）。
  - 弧度大、向下弯 → 富理想与创意，宜文科艺术；平直 → 重现实逻辑，宜理科商业。
  - 下垂至月丘 → 想象丰富、情感细腻、多愁善感。
  - **川字掌**（生命·智慧·感情三线各自分开、不相交）→ 性格独立、敢闯敢拼，往往早年离家、亲缘较淡。

#### 1.3 感情线（天纹 / 父纹）
- **定位**：小指下掌边起，向食指方向走；走入食指与中指缝为**中庸**。
- **核心**：情感、关系、表达。
- **读法要点**：
  - 深细 → 感情细腻；粗浅 → 感情粗放。
  - 头端（掌边）上下都有**羽毛状斜纹** → 很热情；只有线上有（无线下）→ "机智线"，反应好、能随机应变。
  - 链形 → 多愁善感。
  - 末端走向：至食指下 → 偏精神之爱（心灵之域）；入中指下 → 偏肉体之爱、不重海誓山盟；在中指下往下弯 → 爱得任性、不择手段；长且有分岔往下弯 → 为情牺牲一切。
  - 岛纹：出现在**无名指下** → 眼睛问题（近视/弱视/闪光）；其他位置 → 感情困扰。
  - 断裂 → 感情受重大挫折。
  - 长度 = 情感持久度/执着度；超过标准 → 感情深、乐于付出但占有欲也强；较短 → 淡泊、喜简单关系。

#### 1.4 事业线 / 命运线（玉柱纹 / 命運纹）
- **定位**：从掌底（多自腕部）向中指根部（土星丘）上升的垂直纹；并非人人都有。
- **核心**：人生轨迹、事业、社会成就、外部影响。
- **读法要点**：
  - 清晰深长直立、无障碍纹 → 事业顺、意志坚定、得贵人提携。
  - 断断续续多条 → 工作不稳定、常变更环境；中途分支向食指 → 掌权征兆；向无名指 → 名利双收吉象。
  - 升到**智慧线**停止 → 凭个人理智决定停工/转型；升到**岛纹**或感情线停止 → 因感情/家庭因素受阻停工。
  - 有**两条** → 可兼职、副业、多轨发展（"双事业线"）。
  - 起自生命线 → 早年靠家；起自月丘 → 靠外力/远方。
  - 与生命线无交 → 独立打拼。
  - **无事业线** ≠ 没工作/命不好，多表职业方向多变或随遇而安。

### 2. 辅线与特殊功能纹

#### 2.1 太阳线（成功线 / 名利线 / Apollo 线）
- 无名指下（太阳丘）垂直短纹，与事业线平行，又称"第二命运线"。主才名、名声、人缘、贵人与成功机运。
- 清晰深长 → 名利、易因事业成功或贵人得财。
- 成**双线** → "名望纹"，社会上好名声。
- 过多杂线 → 兴趣广但精力分散不专一。
- 岛纹或十字形 → 破坏太阳线，声望或金钱损失。
- 起自生命线 → 凭自身努力成功。
- 短 → 可能中年/家庭稳定后才享成果。

#### 2.2 婚姻线（家风纹）
- 小指下掌边、介于小指与感情线之间的横短纹；数目不重要，总有一条最深为主。
- 两条一样深 → 易陷三角纠纷；超六条且找不出主线 → 婚姻关系较乱。
- 长 → 择偶条件苛、对配偶要求高、婚姻有压力；长到无名指下接太阳线 → 有好亲家、带财富声望；冲破太阳线 → 负面影响声望财富。
- 尾部分岔 → 易分手；岛纹 → 可能因故分居；尾部上翘 → 缺乏结婚意愿。

#### 2.3 健康线（健康纹）
- 自小指下向生命线斜走的纹；**传统认为"没有健康线才最健康"**。
- 断续 → 肠胃消化不良；链状 → 呼吸系统毛病；岛纹头端 → 咽喉/头部，尾端 → 泌尿系统。
- **科学立场**：现代医学不认健康线预测疾病；此条仅作民俗记录，解读需谨慎。

#### 2.4 财运线（Mercury 线 / 水星丘纵线）
- 小指根部（水星丘）垂直短纹，主理财观念、商业头脑与近期财运。
- 清晰深刻 → 近期财运稳；断续/模糊 → 财运不稳；靠近无名指 → 慷慨、花费大但常有偏财/理财运。

#### 2.5 火星线（贵人纹 / 第二生命线 / 祖荫纹 / 阴骘纹）
- 位于生命线内侧的平行弧线。象征祖上积德或自身贵人运强；若生命线较短或有损，清晰火星线可补救、增强体力与化解灾厄。

#### 2.6 金星带（横财纹 / 理财纹）
- 位于感情线上方、呈半月状横于中指与无名指间。
- 美丽弧线 → 审美佳、情感丰富具魅力；呈一条清秀横直线（理财纹）→ 极具理财头脑，宜财务/会计/投资，常有意外之财。

#### 2.7 创作纹
- 无名指与小指指缝下斜斜的两条纹 → 具写作、绘画、学术研究或设计创作天赋，必有所成。

#### 2.8 财富纹（拇指第二节纹）
- 大拇指第二节不论横纹或直纹，纹越多 → 钱财累积越多。

#### 2.9 努力纹 / 希望纹
- 生命线上往上升的纹 → 努力有成果；起自生命线起点向食指下升 → "希望纹"，梦越多运气越好。

#### 2.10 不测纹
- 自中指下往生命线长、上粗下细 → 意外不测之事（传统亦含极端倾向暗示，解读务必极克制、不渲染）。

#### 2.11 人缘纹
- 掌底边上斜往上走 → 有人缘。

#### 2.12 神秘十字纹
- 掌心、感情线与智慧线之间出现十字形 → 喜研究哲学、玄学、宗教。

#### 2.13 反抗纹（叛逆纹）
- 感情线下方一条与之平行的线 → 个性倔强、不屈不挠；若无道德约束则易成社会问题人物。

#### 2.14 小人纹
- 食指根部斜斜的纹；无斜纹不犯小人，常人几条；多于四条 → 易招忌谤；七/八条且有官非象（小指不过无名指第三节）→ 易有官非。

### 3. 丘位（隆起度；2D 照片测不了，需真人触摸）
麻衣称"四周高起而中间洼者富有，四峰肉薄而中间平者财散"。现代多称**八大丘**：
- **金星丘**（拇指根/生命线包围区）：爱欲、活力、温情。饱满 → 热情有活力。
- **木星丘**（食指根）：野心、领导、自信、权欲。丰满 → 有领导欲；有十字纹 → 常得意外成功。
- **土星丘**（中指根）：孤独、责任、律己。凹陷 → 一生劳碌少闲。
- **太阳丘**（无名指根）：艺术、名望、财富。丰满且色泽红润 → 生活富足、审美高雅。
- **水星丘**（小指根）：商业、口才、沟通。有细碎垂直线（财运线）→ 经商头脑、善理财。
- **月丘**（掌外侧、对拇指）：直觉、想象、远方。
- **火星**（上火星=拇指与智慧线间主果敢；下火星=智慧线与金星丘间主体力耐力）。
> **AI 注意**：本工具只定位丘位区域、不测隆起度。凡涉及"丘位隆起"的传统论断，必须标注"需真人触摸确认，2D 照片无法判断"。

### 5. 古典特殊纹词汇（麻衣神相·论掌纹，可作"吉祥图案"的文化底本）
麻衣体系把掌中封闭/特殊图案视为贵格，以下为常见"吉纹"（AI 检出 `wealthMarks` 等图案时可引用其民俗寓意，但须标注"传统视为吉兆、非断定"）：
- **宝钱纹 / 穿线纹** → 招财进宝、追资财。
- **端笏纹 / 插笏纹** → 文官朝列。
- **龟纹** → 将相；**鱼纹** → 郎官/星郎；**双鱼纹** → 位列三公、文章耀祖。
- **偃月纹 / 车轮纹** → 吉庆。
- **阴骘纹 / 延寿纹** → 福寿；**印纹** → 显贵；**金花印纹** → 男封侯、女夫人。
- **田纹** → 富；**井纹** → 福；**山纹** → 富足；**十纹** → 禄；**玉策纹** → 名光万国；**带印纹/兵符纹/拜相纹/雁阵纹/六花纹/悬鱼纹** → 各主功名文职将相。
- **结关纹 / 夜叉纹** → 凶逆、下贱，属负面格。
> 麻衣总纲："纹深而细者吉，纹粗而浅者贱；三纹莹洁无纹破者福禄之相；纵理多者性乱而灾，横理散出指缝者百事破败；纹虽好而冲破者皆有缺陷无成之相。"

### 6. 手型与手指（补足"专业感"的形态维度）
- **四元素手型**（西/印传统，由掌形+指长定 temperament）：
  - **土型**（方掌短指）→ 务实、稳重、接地。
  - **风型**（方/长方掌长指）→ 智性、善沟通、好奇。
  - **火型**（长掌短指）→ 自发、热情、敢冒险。
  - **水型**（长掌长指）→ 创意、敏感、直觉强。
- **手指分析**：
  - 拇指 → 意志力与逻辑；长→意志强，灵活→适应力强。
  - 食指(木星) → 野心领导；中指(土星) → 责任智慧；无名指(太阳) → 创意表达；小指(水星) → 沟通机变。
  - 指距：并拢→谨慎；分开→独立开放。
- **古典掌形/掌色**（麻衣）：手软如绵囊→至富至贵；掌长厚→贵，短薄→贱；掌硬圆→愚，软方→智；掌红如喷血→荣贵，黄如拂土→至贱，青→贫苦，白→寒贱；掌中黑痣→智而富；四周高起中洼→富有，中平→财散；"贵人十指软绵绵"。

### 7. 左右手对照（多传统并存，AI 勿武断）
- **西/印现代主流（Cheiro/Benham）**：惯用手=现世/主动人生；非惯用手=先天潜能。右手写字读右手，左手写字读左手。
- **印古典（Hast Samudrika）**：男右女左为"主动命"，另手为先天（现代多已改采惯用手）。
- **中土各流派不一**：有"男左女右"旧规；有"两手合参、分主过去/现在/未来"；亦有"左先天右后天"。
- **本工具当前**：每只手独立分析、未做左右对照；若用户给定左右手，按"惯用手=后天发展、非惯用手=先天"做软性对照即可，并明示流派差异。

## 二、皮纹学（医学，真实实证 — 非算命）

- 掌纹/指纹在胚胎 10–16 周形成、终身不变，反映胚胎早期发育。
- **仅用于遗传病辅助筛查**（不能替代染色体检查）：
  - 唐氏(21三体)：猿线(simian line)约 50%、atd 角增大。
  - Klinefelter(47,XXY)、Patau(13三体)、Edwards(18三体)、Turner、Cri-du-chat 各有皮纹特征。
- **关键界限**：皮纹学能辅助筛查疾病，但**完全不能**预测性格、命运、寿命、感情。

## 三、科学批判（清醒剂）

- **Dean et al.(1992)**：综述无证据支持手相核心主张。
- **Ben-Shakhar et al.(1986)**：掌纹与性格无关。
- **Wilson & Mather(1974)**：生命线长度与寿命无显著相关。
- **为何"觉得准"**：巴纳姆/Forer 效应（笼统描述人人当专属）、冷读、确认偏误。
- **为何归伪科学**：主张不可证伪、缺乏标准化、各流派互相矛盾、受控测试不超随机。
- **手真正能读出的（合法观察）**：茧/磨损→职业爱好；皮肤状态→年龄日晒；2D:4D 指长比→产前激素（医学统计）；握力→健康寿命因子（医学）。

- `lines[].mark = island` → 岛纹，该阶段减弱（感情线无名指下岛纹传统关联眼疾，可软提及）。
- `lines[].mark = chain` → 链纹，阶段性消耗/混乱（生命线起端链纹=幼年多病，智慧线起端链纹=求学受环境影响）。
- `lines[].depthGradient.type`（uniform/fadeEnd/deepenEnd/midFade）→ 起止深浅走势；`reliable:false` 时标注"噪声大、仅供参考"。
- `lines[].confidence`（高/中/低）→ 该线检测可信度，低时明示"此线结论仅供参考"。
- `topoNodes`（来自青点）→ 拓扑分叉/交汇，位置关键处传统视为节点事件。
- `wealthMarks[]`（金框）→ 财富吉祥图案，`location` 给丘位，`confidence` 给可信度；可引用第五节古典吉纹寓意（元宝/田/井→聚财；三角→聚气专注；双鱼/金花印等→功名），**只说"传统视为吉兆"，不据以断言财运**。
- `careerSpine` → 事业纵脊可见度；可见且清晰 → 事业有主轴（呼应 1.4 双事业线/直立顺遂）。
- `diagnostics.lowConf / skinRatio` 偏低 → 提取质量差，建议重拍，结论置信下调。
- `hand.label` → 掌型（可结合第六节四元素/五行做 temperament 基调，但需真人触摸掌形/指长，2D 仅近似）。
- 左右手：`hand.label` + 用户说明 → 按第七节做软性先天/后天对照。

**默认口径**：每个结论都先说"传统相学认为…（民俗，非医学）"，再给数据依据，最后落回免责。不把任何单一特征放大成"命中注定"。结合多条线/丘/纹做整体叙事（如"强感情线+饱满金星丘+水型手→重情、直觉深"），比单线断言更专业。

## 五、进阶纹向检测（JSON `extraFeatures`）

> 以下三项由工具以**几何启发式**从掌纹掩码+手部关键点算出，属"可检测但置信有限"的进阶维度。
> 输出原始几何量 + 中/低置信，**解读时务必诚实带过、不伪装精确**；噪声大或线尾提取偏杂时明确"建议重拍确认"。

### 5.1 川字掌 / 起点关系（`extraFeatures.chuan`）
- **定义**：三主线（生命线/智慧线/感情线）各自独立、互不相连为"川字掌"。典型标志是**智慧线与感情线起点不相连**（存在明显间隙）；严格川字还需生命线也与智慧线分离。
- **传统义**：独立、自主、意志强、有主见、主观；各流派亦提示亲情缘偏淡（幼年易离父母）、性子较倔。旧说对女性川字掌有"克夫"等争议谬见，现代多视为独立能干。**多流派并存，仅作参考**。
- **JSON 字段**：
  - `isChuan`（bool）：三主线皆独立 → True；否则 False。
  - `mindHeartGap` / `lifeMindGap`：智慧线↔感情线、生命线↔智慧线 的**手长归一化**最近间隙（互斥掩码测得，已避开区域重叠污染）。>0.08 视为分离。
  - `mindHeartSeparate` / `lifeMindSeparate`：对应是否分离。
- **解读映射**：`isChuan=True` → "三主线各自独立，传统视为自主要强、有主见"；若仅 `mindHeartSeparate` 为真而 `lifeMindSeparate` 为假 → "智慧线与感情线末端分离、但与生命线仍相连，非典型川字"；`isChuan=False` → 三主线相连（非川字）。置信以 `confidence`（中/低）示之。

### 5.2 双太阳线（`extraFeatures.sunDouble`）
- **定义**：太阳线（成功线）区域出现**两条并列、细长、竖直延展**的主脊。
- **传统义**：名声/才艺有双线辅助，常主"名利有助、可凭才艺或副业成名"，亦视作才名线强盛之兆。
- **JSON 字段**：`isDouble`（bool）、`count`（达标主脊数）、`bestLen`（最长主脊占手长比）。
- **解读映射**：`isDouble=True` → "太阳线见并列双脊，传统视为才名有助、利于副业/才艺扬名"（置信中）；`count<=1` → "未检出清晰双太阳线"（置信低）。若 `bestLen` 偏小说明该区域仅短线，勿夸大。

### 5.3 感情线羽毛纹（`extraFeatures.heartFeather`）
- **定义**：感情线 **pinky 侧末端**出现短小分叉/支线（羽毛状或树枝状）。检测做法：整条感情线骨架化→定位 pinky 主末端→在其周围 ROI 内取"皱褶减骨架"之光晕，数**不与末端相连的独立小支**（主线自身线宽光晕不计）。
- **传统义**：情感外放、热情、人缘好、异性缘佳（"感情线末端如羽毛，待人热情朋友多"）。末端上扬羽毛多主积极热情；下垂羽毛多主付出较多。
- **JSON 字段**：`has`（bool）、`forks`（分支/小支数）、`tips`（分支末端数）、`tipPts`（绘图点，含主末端）。
- **解读映射**：`has=True` → "感情线末端见分叉/羽毛，传统视为感情外放、人缘好"（置信中）；`has=False` → 末端干净收尾、未见明显羽毛（置信低）。**线尾提取偏杂时此判定最易失真，务必标注低置信或建议重拍确认**。
